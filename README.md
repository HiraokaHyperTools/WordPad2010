`ワードパッド` の廃止が [Windows クライアントの非推奨の機能 | Microsoft Learn](https://learn.microsoft.com/ja-jp/windows/whats-new/deprecated-features) で宣言されて、本当に削除されました

しかし私は自分の作業でワードパッドのようなものが必要であった (NSIS のセットアップ作成で RTF ファイルを編集する用があった) ため、代替品を構築しました
